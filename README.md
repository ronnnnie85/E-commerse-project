# Проект E-commerce Core

## Описание проекта

Проект содержит базовые сущности для работы с товарами и категориями интернет-магазина. 
Реализована система учета товаров, их категоризация, загрузка данных из JSON и базовые операции.

## Реализованная функциональность

### 1. Базовые классы и миксины

#### `BaseProduct` (base_product.py)
- Абстрактный базовый класс для всех продуктов
- Определяет обязательный интерфейс для классов продуктов
- Содержит абстрактный фабричный метод `new_product` для создания экземпляров продуктов

#### `ProductMixin` (product_mixin.py)
- Миксин для добавления общей функциональности продуктам
- Предоставляет:
  - Автоматический вывод строкового представления при инициализации
  - Метод `__repr__` для удобного отображения объекта с его атрибутами
  - Может быть использован любым классом продукта для стандартизированного вывода

### 2. Класс Product
- Хранение информации о товаре:
  - Название (name)
  - Описание (description)
  - Цена (price) с защитой от невалидных значений
  - Количество в наличии (quantity)
- Методы:
  - `new_product` - фабричный метод для создания/обновления товаров
  - Геттер и сеттер для цены с валидацией
  - Защита атрибута цены (__price)
  - Магические методы:
    - `__str__` - строковое представление товара
    - `__add__` - сложение товаров по общей стоимости (цена * количество)

### 3. Класс Category
- Хранение информации о категории:
  - Название (name)
  - Описание (description)
  - Список товаров (products)
- Статистика:
  - Подсчет общего количества категорий (category_count)
  - Подсчет общего количества товаров (product_count)
- Методы:
  - Добавление товара в категорию (add_product)
  - Форматированный вывод товаров (products property)
  - Доступ к списку товаров (products_in_list)
  - Магический метод `__str__` для строкового представления категории

### 4. Классы товаров
- `Smartphone` - смартфоны с дополнительными атрибутами:
  - Эффективность
  - Модель
  - Объем памяти
  - Цвет
- `LawnGrass` - газонная трава с атрибутами:
  - Страна-производитель
  - Период прорастания
  - Цвет

### 5. Итератор товаров (ProductIterator)
- Реализация протокола итератора Python
- Последовательный перебор товаров в категории
- Поддержка циклов for и других итерируемых контекстов

### 6. Утилиты (utils.py)
- `read_data_json` - чтение JSON файла с обработкой ошибок
- `load_data_from_json` - создание объектов Category и Product из JSON данных
- Валидация входных данных
- Обработка ошибок файлов и данных

### 7. Тестирование
- Проверка корректности инициализации объектов
- Проверка подсчета количества продуктов и категорий
- Тестирование методов изменения цены
- Проверка загрузки данных из JSON
- Тестирование итератора товаров
- Проверка наследования классов товаров
- Покрытие тестами более 75% кода

## Архитектура

Проект использует:
- Абстрактные базовые классы (`BaseProduct`) для определения интерфейсов
- Миксины (`ProductMixin`) для добавления общей функциональности
- Наследование для специализированных классов товаров
- Инкапсуляцию для защиты важных атрибутов (цена)
- Полиморфизм через переопределение методов

## Установка и запуск

1. Клонируйте репозиторий
```bash
  git clone https://github.com/E-commerse-project/ecommerce-core.git
  cd ecommerce-core
```
2. Установите зависимости с помощью Poetry:
   ```bash
   poetry install
   ```
3. Активируйте виртуальное окружение:
   ```bash
   poetry shell
   ```
4. Запустите тесты:
   ```bash
   pytest --cov=.
   ```
