# Проект E-commerce Core

## Описание проекта

Проект содержит базовые сущности для работы с товарами и категориями, которые будут расширяться в будущем для создания полноценной системы электронной коммерции.

## Реализованная функциональность

### 1. Класс Product
- Хранение информации о товаре:
  - Название (name)
  - Описание (description)
  - Цена (price) с защитой от невалидных значений
  - Количество в наличии (quantity)
- Методы:
  - `new_product` - фабричный метод для создания/обновления товаров
  - Геттер и сеттер для цены с валидацией
  - Защита атрибута цены (__price)

### 2. Класс Category
- Хранение информации о категории:
  - Название (name)
  - Описание (description)
  - Список товаров (products)
- Статистика:
  - Подсчет общего количества категорий (category_count)
  - Подсчет общего количества товаров (product_count)
- Методы:
  - Добавление товара в категорию (add_product)
  - Форматированный вывод товаров (products property)
  - Доступ к списку товаров (products_in_list)

### 3. Утилиты (utils.py)
- `read_data_json` - чтение JSON файла с обработкой ошибок
- `load_data_from_json` - создание объектов Category и Product из JSON данных

### 4. Тестирование
- Проверка корректности инициализации объектов
- Проверка подсчета количества продуктов и категорий
- Тестирование методов изменения цены
- Проверка загрузки данных из JSON
- Покрытие тестами более 75% кода

## Установка и запуск

1. Клонируйте репозиторий
```bash
  git clone https://github.com/E-commerse-project/ecommerce-core.git
  cd ecommerce-core
```
2. Установите зависимости с помощью Poetry:
   ```bash
   poetry install
   ```
3. Активируйте виртуальное окружение:
   ```bash
   poetry shell
   ```
4. Запустите тесты:
   ```bash
   pytest --cov=.
   ```
